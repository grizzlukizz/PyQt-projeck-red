Планировщик домов



Можно создавать дома и этажи, добавлять комнаты и мебель.
Изображение этажа сохраняется в PNG, а данные — автоматически в SQLite.



Запуск на Windows



1. Установите Python 3.13+ с сайта https://www.python.org/downloads/.
2. Откройте `Проект/Запуск.exe`. При первом запуске нужны интернет и установка PyQt6.
3. Дальше открывайте программу тем же `Запуск.exe`.
4. 

Установка автоматически создаёт `.venv` в папке проекта и записывает зависимости
командой `pip freeze > requirements.txt` в папку `Документы`.



Файлы



* `Проект/main.py` — окно, кнопки и формы добавления/изменения.
* `Проект/plan.py` — рисование этажа, выбор и перетаскивание объектов.
* `Проект/database.py` — SQLite, четыре связанные таблицы и сохранение данных.
* `Проект/Запуск.exe` — запускатель Windows с иконкой флага.
* `Документы/requirements.txt` — зависимости.
* 

База хранится в `%LOCALAPPDATA%\\\\DomPlan\\\\doma.db` и не удаляется при
обновлении программы. Если в папке `Проект` лежит старая база `doma.db`,
она переносится при первом запуске, если в папке данных ещё нет своей базы.



Управление



* Слева список домов и этажей. Справа — план этажа.
* «+ Дом», «+ Этаж», «+ Комната», «+ Мебель» создают объекты.
* «Изменить / удалить» открывает меню действий для выделенного объекта.
* Двойной щелчок открывает изменение, `Delete` удаляет выделенный объект.
* Масштаб меняется кнопками `−` и `+` от 0 до 100%.
* «Сохранить PNG» экспортирует план этажа.
* 

Если программа не открывается, откройте командную строку в папке `Проект` и выполните:



```bat
.venv\\\\Scripts\\\\python.exe main.py
```



Так можно увидеть текст ошибки. Если PyQt6 не установлен,
сначала установите зависимости из `Документы/requirements.txt`.
Не удаляйте `doma.db`, если в нём есть ваши дома.
